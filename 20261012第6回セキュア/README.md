# マイメモ

ユーザー登録・ログインを行い、自分だけが閲覧できるメモを保存する小さなWebアプリです。Python 3.10以降の標準ライブラリのみを使います。

## 起動方法

```powershell
cd 20261012第6回セキュア
py app.py
```

ブラウザーで <http://127.0.0.1:8000> を開いてください。登録したアカウントでログインし、メモを作成できます。データは `notes.sqlite3` に保存されます。

環境変数 `APP_HOST`、`APP_PORT`、`APP_DB_PATH`、`APP_FILES_DIR` で待受先・ポート・データベース・ファイル保存先を変更できます。ファイルは既定で `user_files/<ユーザーID>/` に保存されます。`APP_FILES_DIR` はアプリのフォルダー内にある専用サブフォルダーに限り、フォルダー外のパスやシンボリックリンクは起動時とファイル操作時に拒否されます。HTTPSのリバースプロキシ配下で使用する場合は `COOKIE_SECURE=1` を設定してください。本番運用にはHTTPSが必要です。

## ファイルAPI

すべてのAPIはログイン必須で、各ユーザーのファイルは別々のフォルダーに保存されます。APIはUTF-8テキストのJSONを受け付け、ファイル名は一つのファイル名に限定します。パス区切りやOS上の危険な名前は拒否します。1ファイルは最大1 MiB、ユーザーあたり100ファイル・合計10 MiBまでです。

| メソッド | パス | 内容 |
| --- | --- | --- |
| `GET` | `/api/files` | 自分のファイル一覧と、変更リクエスト用のCSRFトークンを取得 |
| `POST` | `/api/files` | `{"name":"memo.txt","content":"内容"}` で新規作成。既存ファイルは上書きしません |
| `GET` | `/api/files/{name}` | 自分のファイルを読み取り |
| `PUT` | `/api/files/{name}` | `{"content":"更新内容"}` で既存ファイルを更新 |
| `DELETE` | `/api/files/{name}` | 自分のファイルを削除 |

`POST`、`PUT`、`DELETE` には、JSONリクエストとともに `X-CSRF-Token` ヘッダーが必要です。トークンはログイン後に `GET /api/files` を呼び出し、レスポンスの `csrf_token` から取得します。未ログインは `401`、CSRF不正は `403`、他のユーザーのファイルは `404` を返します。ファイル操作中にOSエラーが発生した場合は `500` を返します。

## テスト

```powershell
py -m unittest discover -s tests -v
```

## セキュリティ上の取り扱い

- パスワードはランダムsalt付きPBKDF2-HMAC-SHA256で保存します。
- セッションCookieはHttpOnly・SameSite属性を付け、DBにはCookie値自体でなくSHA-256ハッシュを保存します。
- フォーム送信ではCSRFトークンを検証し、メモ本文はHTMLエスケープして表示します。
- メモの読み書きはログイン中のユーザーIDで絞り込みます。
- ファイルAPIはログインとCSRF検証を必須とし、アプリフォルダー内のユーザー専用ディレクトリにあるテキストファイルだけを操作します。パス逸脱・シンボリックリンクを拒否し、サイズ・ファイル数・合計容量を制限します。
- `AGENTS.md` にあるAIエージェントの作業範囲は指示上のガードレールです。AIツール自体のファイルアクセスをOSレベルで隔離するものではありません。強制的な隔離には、OSの権限・サンドボックス設定が別途必要です。
- このアプリは学習用です。公開運用の前にHTTPS、運用環境の設定、監視、バックアップを整えてください。
